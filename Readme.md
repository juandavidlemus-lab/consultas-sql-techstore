# Consultas SQL - TechStore

## Datos del estudiante

- **Base de datos:** TechStore
- **Herramienta:** xampp

## Objetivo
Realizar 15 ejercicios de consultas SQL de nivel básico, intermedio y avanzado, utilizando la base de datos TechStore para practicar la búsqueda, organización y análisis de datos.

## Ejercicios

### Nivel 1: Básico
1. Productos de la categoría Laptops ordenados por precio.
2. Cantidad de clientes por estado.
3. Empleados con salario superior a $40.000.
4. Productos con menor cantidad de stock.
5. Pedidos realizados en enero de 2025.

### Nivel 2: Intermedio
1. Ventas por método de pago.
2. Productos con stock inferior al mínimo.
3. Ticket promedio por tipo de cliente.
4. Empleados con mayor salario por departamento.
5. Clientes con más de tres compras en un mes.

### Nivel 3: Avanzado
1. Margen de ganancia por categoría.
2. Clientes que compraron en 2023, pero no en 2024.
3. Crecimiento mensual de ventas usando LAG.
4. Mejor vendedor de cada región.
5. Análisis RFM de clientes.

## Archivos
- `consultas.sql`: contiene las consultas SQL.
- `evidencias/`: contiene las capturas de los resultados.

## Conclusión
Esta actividad permite fortalecer los conocimientos de SQL mediante consultas de diferentes niveles de dificultad y aprender a analizar información almacenada en una base de datos.
